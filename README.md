# github-explorer

A React + Vite application to search GitHub users, their repositories, and display details.

## Features
- Search GitHub users by username
- View user profile and repositories
- Responsive design with modern UI

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173 to view the app.
